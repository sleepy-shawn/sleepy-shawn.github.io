Study notes based on RL infrastructure at Microsoft AI by Microsoft AI (November 23, 2026). All figures are from the original article.

We aim to improve capabilities from the base model through RL itself, which means runs of many thousands of training steps spanning weeks to months on thousands of GPUs, rather than a short RL phase at the end of post-training.

Rocket#

Rocket leverages Kubernetes or Slurm to allocate nodes to a job, and Rocket’s components run on Ray as actors. We adopted SGLang as our inference foundation and have substantially adapted it to MAI’s models and long-running agentic RL workloads.

Controlling staleness#

Rocket is an asynchronous RL framework by design, so the learner continues updating while rollouts run.

It seems that in the agentic RL era, asynchronous RL is necessary.

Lag = sample lag + rollout lag + group lag + queue lag

These lags are reasons for rollouts falling behind training.

Each request inherits a priority based on its rollout’s start time.

Automatic scaling.
