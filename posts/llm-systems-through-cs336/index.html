Tensor Operations#

The following einops examples show matrix multiplication, batched matrix multiplication, reduction, and splitting and merging a head dimension.

from einops import einsum, rearrange, reduce

z = einsum(x, y, "seq1 hidden, hidden seq2 -> seq1 seq2")
z = einsum(x, y, "batch seq1 hidden, batch hidden seq2 -> batch seq1 seq2")

summed = reduce(x, "... hidden -> ...", "sum")

split = rearrange(x, "... (heads head_dim) -> ... heads head_dim", heads=2)
merged = rearrange(split, "... heads head_dim -> ... (heads head_dim)")

Computational Costs#

A floating-point operation (FLOP) is a basic operation such as addition (x + y) or multiplication (x * y). Multiplying a B × D matrix by a D × K matrix costs approximately 2 × B × D × K FLOPs, counting each multiply and add separately. Achievable FLOP/s depends heavily on the data type.

Model FLOPs utilization (MFU) is the ratio of the achieved model FLOP/s to the hardware’s theoretical peak FLOP/s.

Two quantities help estimate the cost of an operation: accelerator compute throughput and memory bandwidth. Divide the operation’s FLOPs by the compute throughput to estimate compute time. Divide the bytes transferred by the applicable bandwidth to estimate data transfer time.

  • Accelerator intensity is peak compute throughput divided by peak memory bandwidth. For an H100, this is h100_flop_per_sec / h100_bytes_per_sec.
  • Arithmetic intensity is the number of FLOPs performed per byte transferred by the operation.

Comparing these ratios helps identify whether an operation is compute-bound or memory-bound. Large matrix multiplications in training can be compute-bound. Matrix-vector multiplications typically have lower arithmetic intensity and are more likely to be memory-bound.

Backpropagation and Activation Checkpointing#

For a matrix multiplication, the backward pass computes gradients with respect to both inputs, so it costs about twice as many FLOPs as the forward pass. This estimate applies to the matrix multiplications in MLPs and is also a useful approximation for total model FLOPs at short context lengths.

Activation checkpointing trades memory for computation. It stores selected activations and recomputes the others during the backward pass.
